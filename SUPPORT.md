# Support

PageHold is alpha software. Before requesting help, run:

```bash
./scripts/run-tests.sh
.venv/bin/python websnapshot_admin.py integrity
```

Include the PageHold version, operating system, installation method, visible
error, and relevant redacted log lines. Never include passwords, session cookies,
private signing keys, private archive content, or a runtime database.

Use the [PageHold issue chooser](https://github.com/snurge/pagehold/issues/new/choose)
and select the form that best matches the problem. GitHub issues are public. If
a problem cannot be demonstrated without private material, describe it using a
small synthetic example instead of sharing that material.
