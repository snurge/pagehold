# Contributing

PageHold is currently preparing for its first public alpha release.

1. Read `AGENTS.md`, `README.md`, `ARCHITECTURE.md`, and `DECISIONS.md`.
2. Keep changes focused on the single-account self-hosted product.
3. Preserve polite crawl bounds, private/public authorization, safe replay, and automatic recovery.
4. Never commit runtime data, captures, databases, credentials, keys, logs, or browser profiles.
5. Add tests for changed behavior and run `./scripts/run-tests.sh`.
6. Update the relevant documentation and changelog in the same change.

Contributions are accepted under the repository's `AGPL-3.0-only` license.
